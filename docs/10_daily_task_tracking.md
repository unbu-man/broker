# Chapter X — Daily Founder Task Tracking

**Created:** 2026-11-18  
**Daily-plan window:** 19 November 2026 – 16 February 2027  
**Cadence:** 5 focused hours on 64 weekdays, optional 45-minute Saturday retrospectives, Sunday rest. Around 329.75 planned hours across 90 calendar days; adjust for university commitments.

## Tracking system
A Google-Sheets-compatible `.xlsx` workbook was prepared for the founder in the ChatGPT conversation, titled **BrokerAI_90_Day_Google_Sheets_Tracker.xlsx**. Upload it to Google Sheets to make a permanent editable sheet in the founder's Drive. The workbook was **not** written directly to Google Drive because that account still needs to be connected.

### Workbook tabs
- `Dashboard`: 90-day completion progress, planned/completed/actual hours and weekly progress.
- `Daily Tasks`: one dated task per calendar day, with a `Done ✓` dropdown (☐ or ✓), milestone, deliverable, planned hours, GitHub evidence URL, notes, and actual hours.
- `How to Use`: import and updating instructions.

### Workflow
1. Open Google Sheets; choose **File → Import → Upload** and upload the workbook.
2. Work on the row for today's date.
3. In the `Done ✓` column choose ✓ when complete. Keep ☐ for unfinished.
4. Add evidence in the GitHub link column and record actual hours if desired.
5. Check the Dashboard progress weekly and adjust workload for school.

### Daily routine (weekday)
- Learn fundamentals: 60 min.
- Implement one feature: 180 min.
- Test, reconcile and analyze: 45 min.
- Document and commit evidence: 15 min.
- On heavy university days, use a shorter 2-hour study/build/test session, or move the task.

### 90-day milestone themes
- Days 1–30: business requirements, tooling and validated crypto/forex market data.
- Days 31–60: deterministic virtual order execution, bid/ask spreads, fees, cash/position journal and reconciliation.
- Days 61–90: risk limits, reproducible baseline signals, out-of-sample strategy tests, paper bot monitoring and next-quarter planning.

## Safety and scope
